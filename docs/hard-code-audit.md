# Reference hard-code audit

The reference product contains useful patterns but also SØD-specific assumptions. White Label OS treats the following as configuration rather than constants:

- organization/product name
- departments and panel names
- roles and scopes
- responsible profiles
- closure evidence rule
- undo duration
- locale and timezone
- navigation modules

No SØD user, organization ID, spreadsheet ID, production URL or credential is included in this repository.
